# YOLO meme detector dataset

- Classes: `0 miaocuijiao_cat`, `1 sword_shield_dog`
- Images: 60 (train 48, val 12), 640×640 JPG
- Labels: 60 YOLO bounding-box TXT files
- Exact unique images: 60/60
- Minimum pairwise dHash Hamming distance: 8 / 64
- Generated with varied background, location, scale, rotation, color and mild occlusion from the collected meme variants.
- This is a small starter dataset. For production evaluation, add independently sourced real screenshots to a separate test set.

Network meme imagery can involve creator/platform rights; use for personal research unless permissions are established.
