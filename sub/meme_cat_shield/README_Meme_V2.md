# 妙脆角猫 / 我的刀盾识别项目说明

## 项目目标

训练 YOLO 目标检测模型识别两个固定类别：类别 0 为妙脆角猫（包含头部和妙脆角特征的完整目标框），类别 1 为我的刀盾（刀与盾组成的完整目标框）。普通猫、普通狗、单独的刀或盾、只有文字的 meme 均不作为正类；相似但不属于目标的图像作为困难负样本。

## 数据集来源与自动标注流程

训练数据由多模态 Agent 自动采集和标注：Agent 根据类别描述和用户参考图从公开网页/图片社区检索候选图片；进行去重、尺寸和清晰度筛选；使用视觉模型判断目标并生成矩形框；转换为 YOLO 格式；对低置信度、遮挡、边界不清和困难负样本进行二次检查；最后按原图/派生图分组划分 train、val、test，避免近重复素材泄漏。

自动标注不是人工逐框标注，提交时保留来源清单、生成时间、类别规则和抽检记录。自动爬取不等于获得再分发许可，对外发布前必须核验原始作者和站点许可。

## 数据划分与质量控制

- 训练集约 897 张，验证集约 156 张，测试集约 150 张；另含约 405 张空标签背景/困难负样本。
- 划分前进行 MD5 去重，近重复图按素材组进入同一集合。
- 检查缺失标签、损坏图片、越界框、空标签和类别 ID 合法性。

## 推理与环境

命令：`yolo predict model=weights/meme_detector_best.pt source=/path/to/image_or_video imgsz=640 conf=0.50 save=True`。建议阈值 `conf=0.50`；小目标可将 `imgsz` 调至 960。环境为 WSL Ubuntu-22.04、conda `yolo_env`、Ultralytics 8.4.35、PyTorch 2.8 CUDA、RTX 5060 Laptop。

## 验收结果

独立测试集 Precision 0.964、Recall 0.954、mAP50 0.970、mAP50-95 0.941；37 张困难负样本在阈值 0.50 下无误报。指标代表当前数据分布，部署前应使用现场视频复评。
